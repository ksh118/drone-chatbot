# 🚁 카톡 드론 비행가능지역 챗봇

카카오톡 채널에 장소를 보내면 그곳이 **비행금지구역 / 임시비행금지공역 / 관제권 / 비행제한구역 / 위험구역**에 걸리는지 알려주는 챗봇이에요.
데이터는 드론 원스톱 지도와 같은 **브이월드(V-World) 공역 데이터**를 써요. 전부 무료예요.

## 파일 구성
| 파일 | 하는 일 |
|---|---|
| `api/skill.js` | 카카오가 호출하는 주소 (`/api/skill`) |
| `lib/geocode.js` | 장소 이름 → 좌표 |
| `lib/airspace.js` | 좌표 → 공역 판정 |
| `lib/message.js` | 질문에서 장소 뽑기, 답변 만들기 |
| `test/mock-test.mjs` | 키 없이 돌리는 테스트 (`npm test`) |
| `test/try-real.mjs` | 실제 키로 시험 (`npm run try "장소"`) |

## 환경변수 (Vercel)
| 이름 | 값 |
|---|---|
| `VWORLD_KEY` | 브이월드 인증키 |
| `VWORLD_DOMAIN` | 브이월드에 등록한 서비스 URL |
| `KAKAO_REST_KEY` | (선택) 카카오 REST API 키 |

## 판정 기준
| 결과 | 걸리는 공역 |
|---|---|
| 🔴 비행 불가 | 비행금지구역, 임시비행금지공역, 관제권 |
| 🟠 승인 필요 | 비행제한구역, 위험구역 |
| 🟢 공역상 가능 | 위 구역 어디에도 안 걸림 |
| ⚪ 확인 실패 | 금지/제한 공역 중 하나라도 조회 실패 |

## 주의
- **참고용**이에요. 비행 당일 노탐(NOTAM)과 드론 원스톱을 꼭 확인해요.
- 공역 밖이어도 고도 150m 이상, 야간, 사람 많은 곳 위 비행, 항공촬영은 별도 승인이나 허가가 필요할 수 있어요.
