# 🚁 드론봇: 카톡 드론 비행가능지역 챗봇

카카오톡 채널 **@드론봇**에 장소를 보내면 그곳이 **비행금지구역 / 비행제한구역 / 위험구역 / 관제권**에 걸리는지 알려줘요.
**API 키가 필요 없어요.** 서버가 국토교통부 항공정보간행물(eAIP) 원문을 직접 읽어서 판정해요.

```
사용자: 여의도 한강공원 드론 날려도 돼?
챗봇:  📍 여의도한강공원
       🟠 비행승인이 필요한 곳이에요
       • 비행제한구역 (R75 CAPITAL)
       [드론 원스톱] [노탐 확인]
```

## 동작 방식
1. **장소 → 좌표**: OpenStreetMap Nominatim (키 없음). `KAKAO_REST_KEY`가 있으면 카카오 검색을 먼저 써요.
2. **공역 데이터**: [eAIP](https://aim.koca.go.kr/eaipPub/)에서 지금 발효 중인 판을 자동으로 찾아 읽어요.
   - ENR 5.1: 비행금지(P)·비행제한(R)·위험(D)구역 146개 (원·다각형·두 원 연결형 해석)
   - ENR 2.1: 군 비행장 관제권
   - 민간공항 관제권 18곳: AD 2.2 기준점 + AD 2.17 반경 → `lib/ctr-civil.js`에 저장
3. **판정**: 좌표가 어느 구역 안에 있는지 계산해요. 데이터는 서버 메모리에 6시간 캐시해요.

## 우리 API와 확인용 지도
| 주소 | 하는 일 |
|---|---|
| `/` | 공역 확인 지도 (전체 구역 표시, 지도 클릭·장소 검색으로 판정) |
| `/api/zones` | 전체 구역 GeoJSON |
| `/api/check?lat=37.53&lon=126.93` | 한 지점 판정 |
| `/api/check?q=여의도한강공원` | 장소 이름으로 판정 |
| `/api/skill` | 카카오 오픈빌더 스킬 |

## 파일 구성
| 파일 | 하는 일 |
|---|---|
| `api/skill.js` | 카카오가 호출하는 주소 (`/api/skill`) |
| `api/zones.js`, `api/check.js` | 우리 공역 API |
| `index.html` | 확인용 지도 |
| `lib/aip.js` | eAIP 읽기, 좌표·도형 해석, 구역 판정 |
| `lib/ctr-civil.js` | 민간공항 관제권 (eAIP 2026-11-12 기준) |
| `lib/geocode.js` | 장소 이름 → 좌표 |
| `lib/message.js` | 질문에서 장소 뽑기, 카카오 답변 만들기 |
| `test/mock-test.mjs` | 인터넷 없이 도는 테스트 (`npm test`) |
| `vercel.json` | 서버 지역을 서울(icn1)로 고정 |

## 환경변수 (선택)
| 이름 | 값 |
|---|---|
| `KAKAO_REST_KEY` | 카카오 REST API 키. 넣으면 장소 검색이 더 정확해져요 |

## 판정 기준
| 결과 | 걸리는 공역 |
|---|---|
| 🔴 비행 불가 | 비행금지구역(P), 관제권 |
| 🟠 승인 필요 | 비행제한구역(R), 위험구역(D) |
| 🟢 공역상 가능 | 위 구역 어디에도 안 걸림 |
| ⚪ 확인 실패 | eAIP를 읽지 못함 → "가능"이라고 단정하지 않음 |

## 한계와 주의
- **참고용**이에요. 임시 비행제한(행사·훈련)은 노탐(NOTAM)으로만 나와서 반영되지 않아요. 비행 당일 노탐과 드론 원스톱을 꼭 확인해요.
- 휴전선 일대(P518)처럼 경계가 "휴전선/해안선을 따라"로 적힌 구역은 넓게 잡았어요.
- 민간공항 기준점은 코드에 저장돼 있으니, 공항 관련 AIP 개정이 있으면 `lib/ctr-civil.js`를 확인해요.
- 공역 밖이어도 고도 150m 이상, 야간, 사람 많은 곳 위 비행, 항공촬영은 별도 승인·허가가 필요할 수 있어요.
